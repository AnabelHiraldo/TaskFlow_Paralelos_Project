# Arquitectura MVVM

View:
Pantallas, formularios, botones, listas y navegación.

ViewModel:
Estado de la pantalla, loading, errores y coordinación de acciones.

Repository:
Abstracción de acceso a usuarios/tareas.

Service:
HTTP, URL base, headers, JWT y JSON.

API:
FastAPI expone los endpoints REST.

Database:
PostgreSQL almacena users, tasks y files.

Docker:
Compose levanta API y PostgreSQL.
