# TaskFlow
Proyecto completo para la Actividad Semana 2: backend FastAPI + PostgreSQL + JWT + CRUD + upload + Docker y cliente Flutter MVVM con Future.wait.

Orden de ejecución:
1. Backend: `cd Backend`
2. `docker compose up -d --build`
3. Abrir `http://localhost:8000/docs`
4. Registrar usuario y hacer login.
5. Autorizar Swagger con Bearer token.
6. Instalar Flutter y abrir `Mobile`.
